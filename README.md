# SkyCast 🌤️

SkyCast is a sleek, weather-focused web application that lets users check the current weather for any city with an immersive visual experience.

## Features
- **Immersive Backgrounds:** Video-based background for a premium user experience.
- **Easy Search:** Simple city-based weather lookups.
- **Modern UI:** Clean, responsive design using Google Fonts and Material Symbols.

## Technologies Used
- **Frontend:** HTML5, CSS3, JavaScript
- **Fonts/Icons:** Google Fonts (Nunito), Material Symbols
- **Assets:** Custom video and image assets for visual flair

## Getting Started
1. Clone the repository.
2. Open `index.html` in your browser.
3. Enter a city name and hit "Let's Go"!

## Project Structure
- `/Assets`: Contains background videos, logos, and icons.
- `/CSS`: Styling files.
- `/JS`: Logic and interactivity scripts.
- `/Pages`: Additional information/loading pages.
